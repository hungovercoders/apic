# Working notes

What is here is for people and agents working on apic, not for people using
it. The user documentation is the site, [apic.sh](https://apic.sh/), whose
source is `website/` (see AGENTS.md, Docs site).

- `architecture.md`: the package map, the request lifecycle and the three
  contracts; the one place both are described
- `learn/_template.md`: how to write a lesson for the course, and the rules a
  lesson follows
- `learn/_episode-template.md`: the YouTube title and description for a
  lesson's episode
- `learn/tapes/` and `assets/demo.tape`: the VHS scripts behind the episode
  b-roll and the README's animation
- `.vale/`: the prose style Vale holds the docs to (`task docs:check`)
